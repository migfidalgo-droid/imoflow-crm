# ImoFlow CRM

CRM imobiliário personalizado para gestão de contactos, imóveis, visitas, propostas, processos de venda, tarefas e documentos.

## Abrir localmente

Descarregue o repositório e abra o ficheiro `index.html` num navegador, ou execute `Iniciar ImoFlow.command` no macOS.

Os dados introduzidos na aplicação são guardados localmente no navegador. Utilize regularmente a opção de exportação para criar cópias de segurança.

## Ficheiros principais

- `index.html`: estrutura e ponto de entrada da aplicação.
- `loader.js`: pacote completo com funcionalidades, estilos, localizações e imagens necessárias.
- `Iniciar ImoFlow.command`: inicia a aplicação localmente no macOS.

## Nota

O repositório está privado. A aplicação ainda não está alojada como um website público; o código encontra-se guardado e versionado no GitHub.
