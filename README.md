# ImoFlow CRM

CRM imobiliário personalizado para gestão de contactos, imóveis, visitas, propostas, processos de venda, tarefas e documentos.

## Abrir localmente

Abra o ficheiro `index.html` num navegador ou execute `Iniciar ImoFlow.command` no macOS.

Os dados introduzidos na aplicação são guardados localmente no navegador. Utilize regularmente a opção de exportação para criar cópias de segurança.

## Ficheiros principais

- `index.html`: estrutura da aplicação.
- `styles.css`: apresentação visual.
- `app.js`: funcionalidades e dados locais.
- `locations-portugal.js`: distritos, concelhos e freguesias.
- `assets/`: logótipos utilizados na aplicação e nos documentos.
